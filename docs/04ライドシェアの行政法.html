したがって、その供給きょうきゅうを増やせふやせば、こうした課題かだいは解決かいけつするはずである。もっとも、タクシーの界隈かいわいには、行政ぎょうせい法ほう上のうえの足枷あしかせがあって、それを柔軟にじゅうなんに増やすふやすことはできない。そこで、注目ちゅうもくされているのがライドシェアであり、わが国くにで令和れいわ6年ねん4月がつに解禁かいきんされたのが「日本版にほんばんライドシェア」である。この「日本版にほんばんライドシェア」によって、都市部としぶのタクシー不足ふそくを補うおぎなう。それが政治せいじの目論見もくろみであるい。他方たほう、人口じんこう減少げんしょうが進むすすむ地方ちほうでは、鉄道てつどうやバスの減便げんびん・廃止はいしによって、交通こうつう空白くうはく地ちが生じしょうじている。車くるまの運転うんてんができない人にんは、タクシーを頼りたよりにする。もっとも、需要じゅようが少なけすくなければ、タクシーの経営けいえいは成り立たなりたたないため、そもそもタクシーが殆どほとんど営業えいぎょうしていない地域ちいきもある。

したがって，その供給を増やせば，こうした課題は解決するはずである。もっとも，計程車の界隈には，行政法上の足枷があって，それを柔軟に増やすことはできない。そこで，注目されているのが網約車 / 共享出行 (Ride-sharing)であり，わが国で令和6年4月に解禁されたのが「日本版網約車 / 共享出行 (Ride-sharing)」である。この「日本版網約車 / 共享出行 (Ride-sharing)」によって，都市部の計程車不足を補う。それが政治の目論見であるい。他方，人口減少が進む地方では，鉄道やバスの減便・廃止によって，交通空白地が生じている。車の運転ができない人は，計程車を頼りにする。もっとも，需要が少なければ，計程車の経営は成り立たないため，そもそも計程車が殆ど営業していない地域もある。
ここにもタクシーを呼びよびにくいという状況じょうきょうが存在そんざいし、ライドシェアの出番でばんがある。こうしたライドシェアは「公共こうきょうライドシェア」と呼ばよばれ、「日本版にほんばんライドシェア」が解禁かいきんされる以前いぜんから認めみとめられてきた。ところで、そもそもライドシェアとは何かなにか。その用語ようごの定義ていぎは曖あい味あじであり3，条文じょうぶん上にうえに「ライドシェア」という文言もんごんは見当たみあたらない。海外かいがいにおけるライドシェアは、その形態けいたいが一様いちようでなく、それは幅広いはばひろい意味いみを有すゆうするが、わが国くにで認めみとめられるようになった有償ゆうしょうのライドシェアは、道路どうろ運送うんそう法ほう 78条じょう2号ごうに基づもとづく場合ばあいと同法どうほう78条じょう3号ごうに基づもとづく場合ばあいに限らかぎられる5。

ここにも計程車を呼びにくいという状況が存在し，網約車 / 共享出行 (Ride-sharing)の出番がある。こうした網約車 / 共享出行 (Ride-sharing)は「公共網約車 / 共享出行 (Ride-sharing)」と呼ばれ，「日本版網約車 / 共享出行 (Ride-sharing)」が解禁される以前から認められてきた。ところで，そもそも網約車 / 共享出行 (Ride-sharing)とは何か。その用語の定義は曖味であり3，条文上に「網約車 / 共享出行 (Ride-sharing)」という文言は見当たらない。海外における網約車 / 共享出行 (Ride-sharing)は，その形態が一様でなく，それは幅広い意味を有するが，わが国で認められるようになった有償の網約車 / 共享出行 (Ride-sharing)は，道路運送法 78条2号に基づく場合と同法78条3号に基づく場合に限られる5。

とにかく，自動車を用いたヒトの運送には，適法な形態と違法な形態とがあり，わが国では認められていない違法な網約車 / 共享出行 (Ride-sharing)も存在する。巷では，道路運送法 78条2号に基づく場合を「公共網約車 / 共享出行 (Ride-sharing)」，同法 78条3号に基づく場合を「日本版網約車 / 共享出行 (Ride-sharing)」と呼んでいるが，どちらも法律上の名称ではない。網約車 / 共享出行 (Ride-sharing)の更なる推進には賛否両論が唱えられており，どちらかの見解に本稿が立つわけではないものの，「網約車 / 共享出行 (Ride-sharing)」という語が持つイメージが，その議論の本質に対する理解を妨げているようにすら思われる。カタカナ言葉に用心。

譯文
以下，関連する行政法ネタを織り交ぜながら，計程車に対する規制を取り上げた（II）後わが国の網約車 / 共享出行 (Ride-sharing)事情を紹介する（皿）。無味乾燥な行政法も，実社会における政治経済の動向と深く結び付いており，網約車 / 共享出行 (Ride-sharing)という具体例を素材に眺めれば，その色彩の豊かさが目に映るはずだ。
